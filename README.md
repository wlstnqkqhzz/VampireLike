- Unity 6
- C#
- Visual Studio Code
- Git / GitHub

## 개발 목표
- 뱀서라이크 장르의 핵심 시스템 구현
- 기능별 책임이 분리된 코드 구조 설계
- ScriptableObject를 활용한 강화 데이터 관리
- 캐릭터별 전투 스타일과 전용 강화 설계
- 웨이브, 보스, 히든 보스를 통한 단계적 난이도 구성
- 전투 가독성을 고려한 VFX 및 사운드 피드백 개선
- 메뉴, 옵션, 결과 화면을 포함한 기본 게임 흐름 완성
- 기능 단위 Git 커밋을 통한 개발 과정 기록
