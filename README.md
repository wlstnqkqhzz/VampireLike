# VampireLike

Unity 6으로 개발하는 2D 다크 판타지 뱀서라이크 게임입니다.

## 개발 환경

- Unity 6
- C#
- Visual Studio Code
- Git / GitHub

## 지원 플랫폼

- Windows PC
- Android 테스트 빌드

## 현재 진행 상태

- 기본 이동, 전투, 성장, 웨이브, 보스, 결과 화면까지 핵심 플레이 루프 1차 구현 완료
- 카엘/셀레네 캐릭터 선택과 캐릭터별 능력치, 전용 강화 구현
- Android 세로/가로 화면, 터치 조이스틱, 모바일 HUD, 앱 아이콘 적용
- 남은 주요 작업은 아트/사운드 최종 확정, 모바일 실기 밸런스, 맵 테마 고도화

## 개발 목표

- 뱀서라이크 장르의 핵심 시스템 구현
- 기능별 책임이 분리된 코드 구조 설계
- ScriptableObject를 활용한 강화 데이터 관리
- 캐릭터별 전투 스타일과 전용 강화 설계
- 웨이브, 보스, 히든 보스를 통한 단계적 난이도 구성

- PC와 모바일 양쪽에서 플레이 가능한 기본 게임 흐름 완성
- 기능 단위 Git 커밋을 통한 개발 과정 기록
